## Problem

The HACOM Signal carousel is not completing its intended 400ms track transition. The spotlight variant promotes an incoming narrow card to featured styling, which temporarily changes the carousel viewport's content height. The existing `ResizeObserver` treats every size notification as a real responsive resize and immediately completes the active transition.

Runtime evidence at 1440px:

- The steady story viewport content height was approximately `219px`.
- Starting a spotlight transition caused height notifications near `270px`, `253px`, then `219px`.
- The first height notification arrived about `6ms` after activation.
- At that notification the observer finalized the transition, reset the track transform to zero, and rotated the DOM.
- The browser still delivered frames near 60fps, so the perceived jank is a state discontinuity rather than raw frame loss.

Current resize lifecycle:

```js
// assets/carousel.js:361 — current
const resizeObserver = new ResizeObserver(() => {
  if (phase === 'dragging') cancelDrag();
  else if (phase === 'animating') {
    if (completeTransition) completeTransition();
    else finalize();
  }
  setTransform(0, false);
  updateControls();
  updateIndicators();
  schedule();
});
resizeObserver.observe(root);
```

The observer has no distinction between a true viewport-width change and a height-only change produced by the spotlight card itself.

The incoming featured state can also expand the row vertically while the card is still narrow:

## Target

Keep the current spotlight design, item ordering, arrow mapping, autoplay direction, swipe mapping, and 400ms duration. Remove the premature finalize and vertical row oscillation.

### Inline-size-aware resize handling

Track the last observed inline size and ignore height-only or subpixel-only notifications:

```js
// assets/carousel.js — target contract
const INLINE_SIZE_EPSILON = 1;

function hasMeaningfulInlineSizeChange(previousWidth, nextWidth) {
  return Math.abs(nextWidth - previousWidth) > INLINE_SIZE_EPSILON;
}
```

Inside `initInfiniteCarousel`:

```js
let observedInlineSize = root.getBoundingClientRect().width;

const resizeObserver = new ResizeObserver(([entry]) => {
  const nextInlineSize = entry.borderBoxSize?.[0]?.inlineSize ?? entry.contentRect.width;
  if (!hasMeaningfulInlineSizeChange(observedInlineSize, nextInlineSize)) return;

  observedInlineSize = nextInlineSize;
  if (phase === 'dragging') cancelDrag();
  else if (phase === 'animating') {
    if (completeTransition) completeTransition();
    else finalize();
  }
  setTransform(0, false);
  updateControls();
  updateIndicators();
  schedule();
});
```

Height-only changes generated by the spotlight transition must not call `cancelDrag`, `completeTransition`, `finalize`, or reset the track transform. A real viewport-width change must retain the current safe interruption behavior.
